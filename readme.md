# GangPlan

GangPlan is a shared planning app designed for families, friends, housemates and other small groups who want one simple place to stay organised and connected.

The idea came from wanting a digital version of a shared family noticeboard or fridge door, where everyone can contribute rather than one person managing everything.

## Purpose

GangPlan aims to provide a private shared space where members of a group can:

- Leave messages and notes for each other
- Add events to a shared calendar
- View daily and weekly plans
- Create shared to-do lists
- Create shared shopping or "to buy" lists
- Receive notifications when shared information is added or updated

## User Experience

Users will be able to either:

- Create a Gang
- Join an existing Gang

Each Gang will have its own private shared space.

Examples could include:

- A family household
- A group of friends
- Long-distance friends
- Housemates
- Couples

## Planned Features

### MVP

- User registration and login
- Create a Gang
- Join a Gang using an invite or code
- Shared noticeboard
- Shared calendar
- Shared to-do lists
- Shared shopping lists
- Mobile-first responsive design

### Future Features

- Notifications
- Daily and weekly summaries
- Member profile colours or avatars
- Reactions and comments on notes
- Calendar reminders
- Multiple Gangs per user

## Technologies

The project currently uses:

## Design

GangPlan uses a colourful four-person logo to represent different people contributing to one shared plan.

The application is being designed mobile-first, with a simple and friendly interface.
